# 조선검객 (朝鮮劍客) — 조선시대 액션 방치형 게임

구글 플레이 상위권 방치형 게임 10종 분석([docs/시장분석.md](docs/시장분석.md)) 위에,
**슬레이어 키우기(Slayer Legend)류의 실시간 전투 연출**을 얹은 액션 방치형 RPG 프로토타입.

- **index.html — 조선검객**: 검객이 실시간으로 요괴를 베는 캔버스 전투(달리기·베기 이펙트·데미지 숫자·파티클·보스전 화면 흔들림·챕터별 날씨), 층 등반 + 환생 장기 루프
- **geosang.html — 조선거상(전작)**: 상단 경영 타이쿤형 프로토타입

## 바로 하기

**▶ https://lcyking0923.github.io/idlegame/**

폰·PC 어디서나 열립니다. 폰에서는 브라우저 메뉴의 **홈 화면에 추가**를 누르면
주소창 없이 앱처럼 실행됩니다. 진행 상황은 그 기기의 브라우저에 저장되므로
기기끼리는 공유되지 않습니다.

## 실행 (내 컴퓨터에서)

의존성 없는 단일 HTML 파일입니다. [index.html](index.html)을 브라우저에서 열면 바로 실행됩니다.

```bash
start index.html
```

## 🏯 조선 관제소 — 운영 대시보드

접속자 현황·통계·오류·우편(선물) 발송을 관리하는 운영 서버. Node.js 내장 모듈만 사용(의존성 0).

```bash
node server.js
```

| 주소 | 내용 |
|------|------|
| `http://localhost:8282/` | 조선검객 (접속 추적 활성) |
| `http://localhost:8282/geosang` | 조선거상 (접속 추적 활성) |
| `http://localhost:8282/admin` | **운영 대시보드** |

| 기능 | 내용 |
|------|------|
| 실시간 접속 현황 | 현재 접속(게임별)·오늘 방문·누적 접속자·30초 단위 동시 접속 추이 차트(1h/6h/24h) |
| 접속자 관리 | 진행도(층·품계/칭호·사업)·보유 재화·플레이 시간·IP 실시간 조회, 다중 선택 |
| 로그인 기록 | 누가 언제 어느 게임에 로그인했는지 시간순 기록 |
| 오류 모니터링 | 게임 클라이언트의 JS 오류·Promise 거부를 자동 수집(스택 포함), 24시간 카운트 |
| 우편·선물 발송 | 선택 인원/접속 중 전체/누적 전체에게 냥·비취·영석·보상 상자·도검·기술·영물·유물 첨부 우편 발송 → 게임 내 우편함에서 수령 |
| 공지 | 접속 중인 플레이어에게 즉시 토스트 공지 |
| 강제 퇴장 | 특정 플레이어 차단/해제 (차단 시 게임 접속 불가 화면) |

- 게임 클라이언트는 5초마다 하트비트(`/api/beat`)로 상태를 보고하고, 응답으로 공지·우편·퇴장 명령을 받습니다. `file://`로 열면 자동 비활성화됩니다.
- 냥→(거상)엽전, 비취→(거상)비단으로 변환 지급되며 게임 전용 아이템은 해당 게임에서만 지급됩니다.
- 데이터는 `dashboard-data.json`에 자동 저장됩니다(재시작해도 유지). 실서비스 전에는 `/admin`에 인증을 붙여야 합니다.

## 기술

- 순수 HTML/CSS/JS 단일 파일, 외부 의존성 0
- 배경음악 12곡(`assets/bgm/`, Gemini 생성 국악풍) — 타이틀 1·챕터 5·보스 2·던전 3·전생 스팅어 1, 상황 자동 전환 + 0.8초 크로스페이드, 심연은 0.94배 변속, 파일 없으면 WebAudio 절차 생성 음악으로 폴백 ([docs/배경음악-프롬프트.md](docs/배경음악-프롬프트.md))
- localStorage 자동 저장(15초) + 저장 부호 내보내기/불러오기
- 한국식 숫자 단위(만·억·조·경·해…극), WebAudio 효과음
- 오방색 단청 팔레트 + 한지 질감 단일 테마 UI, 모바일 세로형(430px)

## 실제 출시 시 남은 일

4. 서버 저장·어뷰징 방지, 시즌 이벤트/랭킹 등 라이브옵스
