## 밸런스 모델 v2.2 (공개 자료 기반 원작 구조 재현)

공개 자료에서 확인되는 원작의 수치 구조:
- 몬스터 체력은 구간별로 수십%씩(+큰 스파이크) 증가하는 반면 **재화 증가율은 구간당 약 5~9%에 불과** → 강화 효율이 급락해 벽 발생
- 승급은 공·체에 **대형 배수**(예: Gold 승급 ×25)를 부여하는 주 성장 동력
- 승급전 보스는 준비 없이는 패배하는 강적

이식한 커브:
- 적 체력: 층당 ×1.33 + 챕터(10층)마다 ×2.3 스파이크 / 보스 ×40 (40초 제한 DPS 체크)
- 재화: 층당 ×1.06 + 챕터 ×1.6 — **체력 증가율이 재화를 압도** → 원작형 벽
- 승급 배수 점증: ×3,×3,×4,×4,×5,×5,×6,×6,×8,×8,×10,×10,×12,×12,×15,×15,×20,×25 (누적곱)
- 검증(자동 플레이 시뮬): 10분≈18층 도달 → 이후 10분간 보스 14연속 실패로 정체,
  무과시험 2회→마패→승급 시 돌파 — "벽 → 던전/파밍/소환 → 승급 돌파" 루프 재현

## 그래픽 요구 반영

- 걷는 동안 **6겹 패럴랙스가 항상 스크롤** (구름 0.06× ~ 전경 풀 1.35×)
- 벡터 셀셰이딩 캐릭터 (관절 달리기 사이클, 도포·갓끈 펄럭임, 예비동작→베기→잔상)
- 몬스터 이모지 폐지 → 종족별 프로그래매틱 드로잉 (도깨비/야수/비행/원귀/강시/이무기 + 챕터 팔레트)
- 타격감: 히트스톱, 화면 흔들림, 충격 링, 스파크, 처치 슬로모션, 속도선, 발밑 먼지
