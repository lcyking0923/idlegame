# 조선검객 배경음악(BGM) 제작 명세 + 생성 프롬프트

Google AI Studio의 음악 생성(Lyria / Music 탭) 기준. 프롬프트는 **영어**가 결과가 훨씬 안정적이므로 영어로 작성.
BPM·Density·Brightness 슬라이더가 있으면 표의 값을 참고해 맞춘다.

## 0. 공통 규칙

모든 프롬프트 뒤에 붙일 공통 접미사:

```
instrumental only, no vocals, seamless loop, steady tempo, no intro build-up, no fade in or out, leave midrange headroom for game sound effects, clean mix
```

납품 스펙:

| 항목 | 값 |
|------|-----|
| 포맷 | MP3 128kbps 스테레오 44.1kHz (OGG도 가능) |
| 길이 | 필드 60~90초 / 보스 40~60초 / 던전 45~60초 / 스팅어 8~12초 |
| 루프 | 앞뒤를 이어 붙여도 끊김·박자 밀림 없게. 앞 0.2초 무음, 뒤 페이드아웃 금지 |
| 음량 | 피크 −6dB, 대략 −16 LUFS (효과음이 위에 얹힘) |
| 용량 | 파일당 1MB 이하 목표 (모바일 웹) |
| 경로 | `assets/bgm/<파일명>.mp3` |

## 6. 게임 쪽 연동 시 할 일

- `assets/bgm/` 폴더에 파일 배치
- 기존 `Music` 절차 생성기 → HTMLAudio/WebAudio 파일 재생기로 교체 (0.8초 크로스페이드)
- 전환 트리거: 챕터 변경 / 보스 등장·격파 / 던전 입장·종료 / 승급 시험 / 전생
- 첫 사용자 입력 시 재생 시작(브라우저 자동재생 정책), 설정의 음악 ON/OFF 유지
- 프리로드는 현재 챕터 + `boss.mp3`만, 나머지는 지연 로드
