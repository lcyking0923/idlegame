# 슬레이어 키우기 시스템 이식 명세

참고 스크린샷 37장을 분석해 **시스템 단위**로 정리. 화풍이 아니라 **구조와 정보 밀도**를 맞추는 것이 목표.
조선검객에 이미 있는 것은 ✅, 없는 것은 ❌, 형태만 다른 것은 ⚠️.

## 2. 전투 화면 ★★★

| 참고 게임 | 조선검객 | 할 일 |
|----------|---------|-------|
| **데미지 숫자가 화면 절반 폭**, 붉은 외곽선, 2줄 겹침 | 작고 얌전함 | ❌ 크기·색·겹침 |
| 몬스터 **4~5마리 한 줄** | 최대 3 | ❌ 슬롯 확장 |
| 몬스터마다 얇은 빨간 체력바 | 있음 | ✅ |
| 좌측 **HOT TIME · EVENT** 세로 배너 | 없음 | ❌ |
| 좌측 물약·물고기 등 **광고 버프 아이콘 세로 배치** | 우측 하나 | ⚠️ 재배치 |
| 우측 **퀘스트 · 스크롤** 버튼 | 모험 탭 안 | ❌ 바로가기 |
| 획득 골드/경험치가 **실시간으로 떠오름** (+51,500) | 없음 | ❌ |
| 버프 라벨(전광석화 -!) 중앙 하단 | 배너로 있음 | ✅ |

| 참고 게임 | 조선검객 | 할 일 |

## 4. 캐릭터 탭

### 4-1. 강화 (✅ 1단계 완료)
- 항목별 `Lv.16080`, `64,320 -> 64,324`, 골드 비용 버튼, MAX 표시
- 구매 배수 x100/x10/x1 — 조선검객은 x1/x10/x100/최대 ✅

### 4-2. 성장 (스탯 포인트)
| 참고 | 조선검객 | 할 일 |
|------|---------|-------|
| STAT POINT 상단 표시 + 초기화 버튼 | SP 표시 있음 | ⚠️ 초기화 없음 |
| STR/HP/VIT/LUK/ACC/DODGE, `Max Lv.1,000` | 5계열 | ⚠️ 항목 수 다름 |
| `+1,262 -> +1,301` 증가폭 | 현재만 | ❌ 1단계와 동일 처리 |
| 초록 **+** 버튼 | 있음 | ✅ |

### 4-3. 승급 ❌ 구조 다름
- 참고: **티어 목록** (스톤→브론즈→아이언→…→미스릴→오리하르콘→아케이나이트)
  각 티어에 `공격력 x1 체력 x1`, `권장 레벨 50`, `승급 완료` / `승급 도전`
- 조선검객: 품계 18단계를 한 줄 요약으로만 표시
- **할 일**: 티어를 세로 목록으로 펼치고 배수·권장 레벨·상태를 각각 표시

### 4-4. 클래스 ❌ 없음
- 코스튬 등급(1단계 훈련생 → 디펜더…)마다 `장착 효과 : 승급 공격력/체력 +N%`
- 보유 개수 `3/5` 진행바, N 뱃지
- 하단 **일괄 융합 · 클래스 소환**

### 4-5. 승급 추가 능력 ❌ 없음
- 잠금 목록 (명중 20, 추가 마나 30% …), 페이지 1/2/3/★
- 별도 재화로 해금

## 5. 장비 탭 ❌ 구조 다름

참고는 **4분할 서브탭**: 무기 · 악세 · 유물 · 정령

### 5-1. 무기 / 악세 (격자형)
- 4열 격자, 칸마다 **N 뱃지**, `4등급`~`1등급` 라벨, 하단 `2 / 5` 진행바
- 등급별 배경색 (회색→초록→주황)
- 하단 **일괄 융합** 버튼
- 조선검객: 세로 목록 + 등급 테두리 → ⚠️ 격자로 바꾸면 훨씬 밀도가 높다

### 5-2. 유물 ❌ 없음
- 목록형: 아이콘, 이름, `Max Lv.100`, `Lv.2`, 효과, **강화 성공 확률 97.7%**, `강화 0/1` 버튼
- **확률형 강화**가 핵심 — 실패 개념이 있다
- 조선검객엔 유물 개념 자체가 없음 (거상에는 있었음)

### 5-3. 정령 ❌ 없음 (영물과 유사하나 구조가 다름)
- **동행 중인 정령** 1기 + 잠금 슬롯 2기 (스테이지 200/300 해제)
- 페이지 1/2/3/★, `26/100` 보유 카운터
- 격자에 속성 아이콘(불·물·땅·바람), +/- 로 장착
- **정령 진화**: 3기 → 1기, 진화 / 빠른 진화
- **정령 소환**: 다이아 500(1회) / 5000(11회), 소환 보너스 33/300 게이지

## 6. 동료 탭 ❌ 구조 다름

- 서브탭 **동료 / 전직**
- 동료 4명을 **큰 도트로 나란히**, 각각 Lv과 `3/5` 진행바
- 동료 상세 = 3탭 (**정보 · 승급 옵션 · 외형**)
  - 정보: 직업명(신궁), 이름(엘리), 속성 데미지, **PASSIVE 3종** 각각 `강화` 버튼 + 2종 재화 비용
  - 승급 옵션: 잠금 능력 목록 + 전용 재화
  - 외형: 코스튬 격자, 선택 표시, `장착중`
- **전직**: 클래스(미스틱 엘프 등) 선택 → 승리 보상(다이아·에메랄드) → `시작` (미니 도전)
- 상단에 **속성 재화 4종** (불·물·땅·빛) 표시

## 7. 스킬 탭 ❌ 구조 다름

- 상단 페이지 1/2/3/★, **합성 · 스킬 배우기** 버튼
- `스킬 숙련도 Lv.5  4/20  모든 속성 데미지 +27%`
- 4열 격자, 칸마다 `0/12` 카운터 + **+** 버튼
- 스킬 상세 모달: `[일반] 불꽃 베기`, Lv.6, **AUTO 토글**, 설명,
  `범위 3 이내의 적 모두에게 공격력의 600%로 1회 공격`,
  `필요공격수 12`, `MP 소모 25`, **강화(비용)** / **슬롯 장착**
- **스킬카드 합성**: 일반/고급/레어/영웅/전설 탭, 재료 선택, 자동 선택 / 융합
- **스킬 배우기**: 일반/상급/각성 탭, `[신화] 불기둥` 등,
  필요 재료 = 스킬카드 1/1 + 무기 0/4, `배우기` 버튼, 하단 `스킬 카드 획득`

## 10. 구현 우선순위 (체감 대비 작업량)

1. **전투 화면** (2장) — 데미지 숫자, 몬스터 4~5마리, 사이드 배너, 실시간 획득 표시
2. **장비 4분할 격자** (5-1) — 세로 목록을 격자로, N 뱃지·진행바·일괄 융합
3. **동료 상세 3탭** (6) — 패시브 강화가 성장 축을 하나 더 만든다
4. **스킬 배우기·합성** (7) — 스킬 획득 경로를 카드형으로
5. **승급 티어 목록** (4-3) — 이미 있는 품계를 펼쳐 보이기만 해도 효과
6. **유물** (5-2) — 확률형 강화, 새 성장 축
7. **지역 선택** (8) — 던전 지도와 통합
8. **절전모드** (9) — 방치형에 잘 맞는 편의 기능
9. **정령/클래스/승급 추가 능력** — 새 시스템이라 가장 큼

> 조선검객 세계관에 맞춰 이름은 바꾼다.
> 정령 → 영물 · 유물 → 보패(寶貝) · 클래스 → 무맥(武脈) · 스킬카드 → 비급(祕笈)
