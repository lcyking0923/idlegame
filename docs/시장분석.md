# 방치형 게임 시장 분석 — 상위권 10개 게임 벤치마킹

> 작성일: 2026-08-17 · 목적: 조선시대 컨셉 방치형 게임 「조선거상」 설계 근거

## 1. 시장 배경

- 국내 모바일 게임 시장에서 방치형 장르 매출 점유율은 2020년 1.7% → 2024년 **16%로 4년 만에 약 10배** 성장 (2025 게임백서).
- MMORPG의 과도한 과금·플레이타임 피로로 이용자가 방치형 RPG로 대거 이동 (MMORPG MAU 70~90% 감소).
- 하이브리드 수익화(IAP+보상형 광고)가 단일 모델 대비 압도적: **D90 ROAS 146% vs IAP 단독 93%, 광고 단독 58%** (AppSamurai).

## 3. 공통 성공 요인 8가지 → 「조선거상」 반영

| 성공 요인 | 근거 게임 | 조선거상 반영 |
|-----------|-----------|----------------|
| ① 첫 10분의 폭발적 성장 쾌감 | 버섯커, 카피바라 | 시작 직후 탭 몇 번으로 사업장 개업·승급이 연쇄로 터지는 초반 곡선 |
| ② 자동화 해금의 쾌감 | Idle Miner, AdCap | 사업장별 「일꾼 고용」 = 매니저 자동화 (수입 ×3) |
| ③ 배수 마일스톤 | AdCap, 메이플 | 사업장 25/50/100/200단마다 수입 ×2 |
| ④ 프레스티지 장기 루프 | AdCap, 버섯커(전직) | 「가문 계승」 → 명성 획득, 명성 1당 전체 수입 +2%, 칭호 승급(보부상→거상→천하제일상) |
| ⑤ 수집·가챠 도감 | 버섯커, AFK, 세나키 | 「보물상자」 유물 가챠 16종 (민화/보물/국보/어보 등급, 중복=강화, 천장 있음) |
| ⑥ 명확한 단기 목표 체인 | 카피바라, 세나키 | 「어명」 24연차 퀘스트 체인 + 단계형 업적 |
| ⑦ 방치 보상 상한 → 복귀 유도 | Idle Miner, 고양이 스낵바 | 오프라인 보상 기본 4시간 상한 (비단으로 8h/24h 확장) → 재접속 동기 |
| ⑧ 하이브리드 수익화 | 고양이 스낵바, 슬라임 | 보상형 광고(수입 ×4 부스트, 무료 비단, 오프라인 2배) + IAP(비단 패키지, 타임워프, 광고 제거) |

## 4. 수익화 설계 (하이브리드)

**보상형 광고 슬롯 (비과금층 LTV):**
- 소문의 바람: 광고 시청 → 2분간 전체 수입 ×4 (쿨타임 8분)
- 무료 비단: 광고 시청 → 비단 +20 (쿨타임 5분)
- 오프라인 보상 ×2: 복귀 시마다 노출 (최고 전환율 슬롯)

**IAP 슬롯 (과금층):**
- 비단 패키지 3종 (₩5,900 / ₩19,000 / ₩49,000)
- 시간 도약(2시간 수입 즉시), 왕실 후원(24시간 ×2 버프)
- 방치 상한 확장 (8h/24h), 광고 제거 (₩12,000)

> 프로토타입에서는 광고·결제가 데모 버튼으로 시뮬레이션되어 있으며, 실제 출시 시 AdMob 보상형 광고 SDK와 Google Play Billing을 해당 슬롯에 연결한다.

## 5. 차별화 포인트

- **조선시대 상단 테마**: 키우기류가 판타지 일색인 시장에서 국밥집·주막·포목점·무역선으로 이어지는 「거상 성장 서사」는 국내 유저에게 직관적이고 친숙 (드라마 「거상」·「미스터 션샤인」류 정서).
- 엽전·비단·어명·계승 등 **재화와 시스템 명칭까지 테마와 일치** → 세계관 몰입이 곧 UX.
- 한지·단청·오방색 기반의 고유 비주얼 아이덴티티.
